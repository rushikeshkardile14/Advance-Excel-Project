# 🏅 Olympics Dashboard -- Excel

An interactive **Olympics Dashboard built in Microsoft Excel** to
analyze Olympic participation, events, medals, countries, sports, and
athlete trends over time.

The dashboard uses PivotTables, PivotCharts, slicers/filters, and Excel
visualizations to turn historical Olympic data into an
easy-to-understand interactive report.



## 📊 Dashboard Overview

The dashboard provides a high-level view of Olympic history and allows
users to explore important trends through charts and filters.

### Key Performance Indicators

-   **Total Olympics:** 51 editions
-   **Total Participants:** 135K+
-   **Total Events:** 765
-   **Total Medals:** 40K+
-   **Gold Medals:** 13,372
-   **Silver Medals:** 13,116
-   **Bronze Medals:** 13,295

> KPI values are based on the dataset used for this dashboard.

## 📈 Visualizations Included

### 1. Country's Participation Over the Years

A world map showing the countries participating in the Olympics and
their level of participation.

### 2. Athletes Participation Over the Years

A line chart showing how athlete participation has changed across
different Olympic editions.

### 3. Medals Over the Years

A trend chart comparing the number of **Gold, Silver, and Bronze
medals** awarded over time.

### 4. Top 10 Countries by Total Medals

A horizontal bar chart ranking the top countries according to their
total medal count.

### 5. Top 5 Sports by Total Medals

A doughnut chart showing the sports contributing the largest share of
total medals.

## 🎛️ Interactive Filters

The dashboard includes filters that allow users to explore the data from
different perspectives:

-   **Summer / Winter Olympics**
-   **Female / Male participants**

These filters make it easier to compare Olympic participation and
performance across different categories.

## 🔍 Key Insights

Some of the major observations visible in the dashboard include:

-   The number of Olympic participants has increased significantly over
    time.
-   The **United States** has the highest total medal count among the
    countries shown.
-   Athletics contributes the largest share among the top five sports by
    total medals.
-   Medal counts generally increase across later Olympic editions as the
    number of events and participation grows.
-   The dashboard makes it easier to compare medal performance and
    participation across Olympic editions.

## 🎯 Project Objective

The main objective of this project is to demonstrate how **Excel can be
used to transform raw Olympic data into an interactive analytical
dashboard**.

This project focuses on:

1.  Cleaning and organizing Olympic data.
2.  Creating meaningful KPIs.
3.  Building PivotTables and PivotCharts.
4.  Adding interactive filters.
5.  Presenting historical Olympic trends in a professional dashboard
    format.
6.  Making data analysis easier for users through visual storytelling.

## 🚀 How to Use

1.  Download the Excel workbook.
2.  Open it in Microsoft Excel.
3.  Go to the **Dashboard** sheet.
4.  Use the **Summer/Winter** and **Female/Male** filters to explore the
    data.
5.  Review the KPI cards and charts.
6.  Use the PivotTable sheet if you want to explore the underlying
    analysis.
